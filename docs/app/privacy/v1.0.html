Tapylet モバイルアプリ プライバシーポリシー

制定日: 2026年9月8日

1. はじめに

株式会社chaintope（以下「当社」）は、モバイルアプリケーション「Tapylet」（理由の如何を問わずサービスの名称または内容が変更された場合は、当該変更後のサービスを含み、以下「本アプリ」）におけるお客様のプライバシーを尊重し、本アプリを提供しております。本プライバシーポリシー（以下「本ポリシー」）は、iOSアプリケーションおよびAndroidアプリケーションとして提供される本アプリに適用されます。

本ポリシーは、本アプリにおける情報の取り扱いについて説明するものです。なお、当社は、お客様の個人情報（個人情報の保護に関する法律第2条第1項に定める「個人情報」を意味します）を直接取得せず、取得する個人関連情報をもってしても特定の個人を識別することはできないことを確認します。

2. 収集する情報

2.1 収集しない情報

本アプリは、以下の情報を収集しません。

  • 秘密鍵
  • ニーモニックフレーズ（シークレットリカバリーフレーズ）
  • ウォレットのパスワード
  • 個人を特定できる情報（氏名、住所、電話番号等）
  • 位置情報、連絡先、写真、広告識別子
  • カメラで読み取った画像（2.5参照）
  • お客様の端末における本アプリ以外の利用状況

本アプリは、利用状況の分析、広告配信、およびそれらを目的とした第三者のSDKの組み込みを行いません。

2.2 端末内に保存される情報

以下の情報は、お客様の端末上にのみ保存され、当社のサーバーには送信されません。

  • 暗号化されたウォレットデータ
  • アカウント情報（アドレス、残高等）
  • ネットワーク設定
  • トランザクション履歴

保存先は、ご利用のOSに応じて次のとおりです。

  • iOSアプリケーション: アプリ専用の保存領域。うちウォレットデータは、パスワードから導出した鍵で暗号化したうえでKeychainに保管します
  • Androidアプリケーション: アプリ専用の保存領域。うちウォレットデータは、パスワードから導出した鍵で暗号化したうえで、Android Keystoreが保護する保存領域に保管します

2.3 ブロックチェーンに記録される情報

本アプリを通じて実行されたトランザクションは、接続先のTapyrusブロックチェーン（Tapyrus Testnetまたは当社が提供するTapyrus API（理由の如何を問わずサービスの名称または内容が変更された場合は、当該変更後のサービスを含み、以下同じ）上のネットワーク）上に記録されます。ブロックチェーン上の情報は誰でも閲覧でき、その性質上、一度記録された情報を事後に削除または変更することはできません。

2.4 外部サービスへのアクセスに伴う情報

本アプリは、以下の目的で外部のサーバーと通信します。

  • 残高およびトランザクション履歴の取得、トランザクションのブロードキャスト（Tapyrusノード／API）
  • トークンメタデータの取得（Token Registry。GitHub Pages上で公開されています）
  • 本アプリの最小サポートバージョンの確認（当社がGitHub Pages上で公開しているファイル）
  • トークンのアイコンおよび画像の取得（トークンの発行者がToken Registryに登録したURL。当社の管理下に無いサーバーであることがあります）

最小サポートバージョンの確認のための通信は、ウォレットを作成する前を含め、本アプリを起動するたび、およびバックグラウンドから復帰したときに行われます。

この通信に伴い、IPアドレス、アクセス日時、端末の種類等の接続情報が、これらのサーバーのアクセスログとして自動的に記録されることがあります。当社が運用するサーバーのアクセスログは、サービスの維持、不具合や障害の調査、および不正利用の防止の目的でのみ利用されます。GitHub Pagesは、GitHub, Inc.が運営するサービスです。同社におけるアクセスログの取扱いについては、同社が公表するプライバシーポリシーをご確認ください。トークンのアイコンおよび画像の取得先は、トークンの発行者が指定するサーバーです。当社はその運営者による情報の取扱いに関与しません。

2.5 カメラの利用

本アプリは、送金先アドレスのQRコードを読み取るためにカメラを使用します。カメラの映像は端末内でのみ処理し、読み取った画像を保存することも、当社その他の第三者へ送信することもありません。カメラの利用にはお客様の許可が必要であり、許可しない場合でも、アドレスを手入力してご利用いただけます。

3. 情報の利用目的

端末内に保存された情報は、以下の目的でのみ使用されます。

  • ウォレット機能の提供
  • トランザクションの作成および署名
  • 残高およびトランザクション履歴の表示

4. 情報の第三者提供

当社は、お客様の情報を第三者に提供、販売、または共有しません。

ただし、本アプリは以下の外部サービスと通信を行います。

  • Tapyrusノード/API: トランザクションのブロードキャストおよびブロックチェーンデータの取得のため（接続先のネットワークに応じて、Tapyrus Testnetまたは当社が提供するTapyrus APIのエンドポイント）
  • Token Registry: トークンメタデータの取得のため（GitHub Pages上の https://chaintope.github.io/tapyrus-token-registry/ ）
  • GitHub Pages: 本アプリの最小サポートバージョンの確認のため（https://chaintope.github.io/tapylet/ ）
  • トークンのアイコン・画像の配信元: トークンのアイコンおよび画像の取得のため（トークンの発行者がToken Registryに登録したURL）

これらの通信において、通信の目的に応じ、お客様のウォレットアドレス、トランザクション情報、およびトークン識別子（ColorID）が送信されます。また、通信に伴い接続情報がアクセスログとして記録されることがあります（2.4参照）。

このほか、お客様が本アプリ内のリンクを操作した場合、以下のページがブラウザで開きます。開いた先での情報の取扱いは、それぞれの運営者が公表するプライバシーポリシーによります。

  • トークンの登録を申請するためのGitHub（https://github.com/ ）の申請ページ。申請はお客様ご自身がGitHub上で行うものです
  • トランザクションまたはトークンを表示するためのブロックチェーンエクスプローラのページ
  • トークンのメタデータに記載された、発行者のウェブサイトその他のURL。これらは発行者が指定するものであり、当社の管理下にありません

また、ご利用中の版が最小サポートバージョンに満たない場合、更新のためにApp StoreまたはGoogle Playのページを開くことがあります。その際の情報の取扱いは、Apple Inc.またはGoogle LLCが公表するプライバシーポリシーによります。

5. データの保管

5.1 保管場所

すべてのウォレットデータは、お客様の端末上に保存されます。保存先は2.2に記載のとおりです。当社はこれらのデータを保持しません。

暗号化されたウォレットデータは、iOSではiCloudバックアップの対象から外れ、他の端末に復元されない設定で保管します。Androidでは、端末のバックアップの対象から除外しています。

アカウント情報、トランザクション履歴および設定については、iOSではiCloudバックアップに含まれることがあります。Androidでは、バックアップの対象に含めていません。バックアップに含まれる場合の情報の取扱いは、Apple Inc.が公表するプライバシーポリシーによります。

5.2 暗号化

秘密鍵等の機密情報は、お客様が設定したパスワードから導出した鍵により暗号化された状態で保存されます。当社はパスワードを保持しないため、パスワードを失念した場合、暗号化されたデータを復号することはできません。

5.3 データの削除

本アプリをアンインストールすると、端末上に保存されたデータが削除されます。ただし、iOSでは、Keychainに保存された情報がアプリの削除後も端末に残る場合があります。この場合でも、本アプリは残った情報を読み込みません。本アプリを再びインストールしてウォレットを作成または復元した時点で、残った情報は上書きされます。

削除前にニーモニックフレーズをバックアップしていないときは、ウォレットの復元は不可能となります。

6. セキュリティ

当社は、本アプリのセキュリティ向上に努めていますが、インターネット上での完全なセキュリティを保証することはできません。お客様は、以下の点についてご自身で対策を講じてください。

  • ニーモニックフレーズの安全な保管
  • 強固なパスワードの設定
  • 端末のセキュリティ維持（画面ロックの設定、OSの更新等）
  • フィッシング詐欺への注意

7. お子様のプライバシー

本アプリは、18歳未満の方による単独での利用を想定していません。未成年の方は、親権者など法定代理人の同意を得たうえで本アプリを利用してください。

8. 本ポリシーの変更

当社は、必要に応じて本ポリシーを変更することがあります。重要な変更がある場合は、本アプリ内または当社ウェブサイトにて通知します。
